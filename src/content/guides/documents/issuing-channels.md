## 받아오는 곳 (경로 기준)

| 무엇 | 창구 | 저장 요령 |
| --- | --- | --- |
| 카드 이용내역 | 카드사 홈·앱 (월별·가맹점별 다운로드) | 엑셀 원본을 그대로 보관, 가공본과 분리 |
| 카드 매출전표·이용대금명세서·금융거래조회서 | 카드사 홈·앱·ARS. **명의(개인·법인)와 권한에 따라 창구가 달라집니다** | 발급 화면이 개편되면 경로를 못찾습니다. 받은 날 파일명부터 붙입니다 |
| 현금영수증 발급내역 | 홈택스 조회 | 월별로 조회해 화면 캡처 + 발급목록 파일 둘 다 |
| 세금계산서 수취·발행 내역 | 홈택스 조회 | 발행월 단위로 정리하면 집행 기간 대조가 쉽습니다 |
| 각종 증명·확인서 | 홈택스·정부24·관할 기관 | **발급 화면을 재조회하기 어렵습니다.** 받은 즉시 PDF 로 저장 |
| 업종별 인허가·신고 확인 | 정부24·관할 지자체 | 처리번호·발급일을 메모로 남깁니다 |
| 플랫폼·온라인 결제 내역 | 각 플랫폼 관리자 화면 | 주문·정산 내역 다운로드 + 화면 캡처 |

## 자주 막히는 지점

1. **인증 준비** — 공동인증서·간편인증이 없으면 그날 조회가 막힙니다. 급할 때가 아니라 전에 한 번 로그인해 보세요.
2. **검색어** — 증명 서류는 세무 실무 표현으로 검색하면 안 나오는 경우가 있습니다. 실패하면 해당 창구의 목록 페이지를 직접 펼칩니다.
3. **가맹점명 불일치** — 카드 내역에 뜨는 이름과 계약·영수증의 사업자가 다른 사례가 많습니다. 그때마다 메모에 "같은 거래처" 라고 표시해 두면 대조에서 안 잃습니다.
4. **취소·환불** — 취소분이 원 결제와 다른 달에 잡히면 월 대조가 맞지 않습니다. 취소 사실 자체를 입력에 남깁니다.

## 이름표 규칙

`YYYYMMDD_거래처_종류` 로 통일하면 정산 제출 폴더에서 파일을 고를 때 눈으로 확인하는 시간이 줄어듭니다.
