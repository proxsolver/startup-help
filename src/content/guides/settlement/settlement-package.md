## 정산 꾸러미가 만들어지는 순서

1. **집행내역 집계** — 기간별로 결제한 지출을 한 장으로. 도구에서 월·비목 합계가 여기서 나옵니다.
2. **지출별 증빙 대응표** — 지출 한 건에 어떤 서류가 붙는지 1:1 로 줄을 세운 표. 대개 정산에서 문제가 되는 건 집계표가 아니라 이 대응표의 빈 칸입니다.
3. **빈 칸 처리** — 미수취·사본뿐·재요청 항목을 목록으로 뽑아 되돌립니다 → [서류를 못 받은 거래 되돌리기](/guide/expense/missing-voucher/)
4. **집행 기간 확인** — 기간 외 날짜의 지출이 섞여 있으면 미리 구분해 둡니다(어떻게 취급되는지는 지침 확인 필요).
5. **인건비 별도 묶음** — 근로·지급 기록, 4대보험 취득·납부, 원천세 신고가 함께 가야 하는 영역이라 다른 비목과 서류 구성이 다릅니다.
6. **제출 후 보완 요구 대응** — 요구받는 항목을 다시 정리 도구에서 상태 `보완 요청` 으로 표시해 추적합니다.

## 준비할 때 쓰는 표 형태

도구의 CSV 열은 이 흐름에 맞춰 놓였습니다: `지출일 · 비목 · 거래처 · 금액 · 결제경로 · 전용카드(Y/N) · 집행기간 · 증빙종류 · 수취상태 · 제출상태 · 메모`.

| 제출상태 값 | 뜻 |
| --- | --- |
| 미제출 | 아직 꾸러미에 안 들어감 |
| 초안 포함 | 제출 초안에는 넣었으나 최종 전 |
| 제출 완료 | 실제로 제출한 건 |
| 보완 요청 | 제출 뒤 재요청 받은 건 |

## 확인해야 할 것 (비워 둔 이유)

- 제출 서류의 정확한 목록과 서식 → 담당 주관기관 정산 안내
- 정산·보고 제출 시점 → 협약서·공고문에 적힌 기간
- 불인정 항목·반납 절차 → 사업 지침 (여기가 참여자에게 가장 아픈 부분이라 **틀린 정보보다 빈칸이 낫습니다**)
- 자금 집행의 회계 처리·부가세 문제 → 세무 대리인 확인

문의 창구: 국번 없이 1357 (모두의 창업 안내), 배정된 담당 주관기관.
