## 매달 5단계

1. **모으기 (5분)** — 카드 이용내역, 현금영수증 발급내역, 거래처에서 받은 서류 파일, 플랫폼 주문내역을 한 폴더에 모읍니다.
2. **입력 (10분)** — [집행 정리 도구](/tools/receipts/) 에 한 줄씩 넣습니다. 서류를 못 받은 건은 수취 상태를 `미수취` 로 두고 **지출 자체를 빠뜨리지 않는 것**이 먼저입니다.
3. **대조 (3분)** — 카드사·은행 내역의 월 총액과 도구의 `총 집행액`을 맞춥니다. 건수가 아니라 총액으로 보면 누락이 먼저 드러납니다.
4. **구멍 찾기 (2분)** — 수취 상태 `미수취`·`재요청함` 필터, 집행 기간 `확인 필요` 필터, 제출 상태 `미제출` 필터를 각각 돌려 개수를 적어 둡니다.
5. **내보내기 (1분)** — CSV(정리·제출용) + JSON 백업(이관용) 두 장을 저장합니다.

## 대조 표를 한 장 만들어 두면 편합니다

| 확인 항목 | 카드·은행 내역 | 도구 합계 | 차이 |
| --- | --- | --- | --- |
| 월 총액 |  |  |  |
| 건수 |  |  |  |
| 취소·환불 건 |  |  |  |

취소·부분환불이 카드 내역과 도구 양쪽에서 서로 다른 달에 잡히는 일이 가장 흔한 불일치입니다.

## 비목 이름 규칙

배정된 예산과목과 도구 분류 이름을 **같은 단어로** 쓰세요. 도구의 비목 입력은 자유 입력입니다(목록은 예시). 두 체계가 따로 놀면 정산표에서 두 배로 대조해야 합니다.

## 백업이 필요한 이유

도구 데이터는 **이 브라우저에만** 있습니다. 시크릿 창, Safari 의 장기 미사용 데이터 정리, 브라우저 초기화, 노트북→데스크톱 이동에서 사라집니다. 마감 때마다 JSON 백업 두 개를 다른 위치(개인 클라우드·USB)에 두는 습관으로 충분합니다.
